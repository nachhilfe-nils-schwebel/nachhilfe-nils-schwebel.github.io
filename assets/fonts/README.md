# Fonts

The site hosts the Latin WOFF2 files locally. DM Serif Display is used for main headings; DM Sans is used for body text and controls.

- [DM Serif Display](https://fonts.google.com/specimen/DM+Serif+Display): regular 400, supplied unchanged by Google Fonts. License: `DM-Serif-Display-OFL.txt`.
- [DM Sans](https://fonts.google.com/specimen/DM+Sans): variable weight 400–700, supplied unchanged by Google Fonts. License: `DM-Sans-OFL.txt`.

Sourced from the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=DM+Sans:opsz,wght@9..40,400..700&family=DM+Serif+Display&display=swap). German umlauts, ß and the euro sign are included. Other characters use the configured fallback fonts when needed.
